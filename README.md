# PostgreSQL DBA Toolkit 🐘

A collection of PostgreSQL administration, monitoring, performance tuning,
maintenance and troubleshooting scripts developed from practical DBA experience.

The goal of this repository is to provide reusable SQL scripts for diagnosing
and managing PostgreSQL environments.

> **Note:** All examples are generic and anonymized. No production data,
> credentials, hostnames or organization-specific information are included.

## 📂 Repository Structure

| Directory | Purpose |
|---|---|
| `monitoring/` | Sessions, connections, locks and database activity |
| `performance/` | Query performance, indexes, bloat and statistics |
| `maintenance/` | VACUUM, ANALYZE and database maintenance |
| `replication/` | Replication status and lag monitoring |
| `security/` | Roles, privileges and access auditing |
| `troubleshooting/` | Diagnostic queries for common PostgreSQL incidents |

## 🔍 Topics Covered

- Active and idle sessions
- Blocking sessions and locks
- Long-running queries
- Database and table sizes
- Index usage
- Table and index bloat
- VACUUM and ANALYZE monitoring
- PostgreSQL replication
- Replication lag
- Roles and privileges
- Connection troubleshooting
- Performance diagnostics
